# 看板工场

一个本地运行的 AI 看板工作区：根据业务场景、指标大纲、Excel/CSV 或数据库元数据生成看板原型，并为指标配置字段映射、SQL 和跳转链接。

## 当前能力

- DeepSeek 生成指标大纲、可视看板与取数参数契约
- 上传 Excel、CSV、原型图和数据库结构作为参考
- 连接 MySQL、SQL Server、Oracle、达梦 DM8
- 从 `ctl_tbl` 与 `fg_columns` 手动同步轻量结构摘要
- 按指标选择性检索候选表和字段，AI 补全 SQL
- 在线数据库模式支持只读 SQL 验证和指标实时取数，离线模式使用模拟数据
- 每个指标可配置详情页链接，预览时新窗口跳转
- 本地保存项目状态、AI Key 和数据库连接配置

## 本地启动

```powershell
npm install
npm start
```

然后访问 `http://127.0.0.1:4173/`。

## 安全说明

- DeepSeek API Key 和数据库密码不会写入仓库或浏览器存储。
- 本机密钥和数据库配置保存在 `%LOCALAPPDATA%\DashboardStudio`。
- 数据库连接建议使用只读账号。
- SQL AI 补全按指标检索相关元数据，不会把全库字段一次性发送给模型。
